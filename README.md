# LLM Prompt Lab

一个持续记录、测试与改进 LLM 提示词的小型实验仓库。

这里不追求“万能提示词”，而是保留可复用的提示词、可验证的案例，以及实验过程中得到的判断。

## 仓库里的三类内容

1. **Prompts**：可直接使用的提示词模板。
2. **Evals**：用于检查提示词是否真的稳定有效的测试案例。
3. **Tools**：不依赖 API Key 的小工具，用来检查提示词文件和整理实验。

## 从哪里开始

- 试用第一个模板：[中文写作教练](prompts/chinese-writing-coach.md)
- 用测试集检查它：[写作教练评测](evals/chinese-writing-coach.json)
- 运行提示词检查器：`python3 tools/prompt_linter.py prompts/`

## 实验记录模板

每次改一个提示词时，记录：

```text
目标：
改动：
测试输入：
观察结果：
结论 / 下一步：
```

## 原则

- 不提交 API Key、真实私密对话或客户资料。
- 一个提示词只解决一个清晰问题。
- 先有 3–5 个测试案例，再说“这个提示词好用”。
